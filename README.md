# 🚀 Satyam Maurya — Personal Portfolio

> A minimalist, zero-framework portfolio website built strictly with **pure semantic HTML5**. No CSS frameworks, no JavaScript bloat—just clean, accessible, and structured markup.

---

## 📌 Project Overview

This portfolio serves as my personal digital home on the web. As a 1st-year B.Tech IT student, I built this project to master core web fundamentals, clean DOM structure, and semantic HTML conventions from the ground up.

### Key Sections:
- **Header & Introduction:** Personal bio and academic background at USICT.
- **Achievements:** Academic milestones, SIH wins, and event presentations.
- **Skills & Stack:** Categorized breakdown of programming languages, soft skills, and developer tools.
- **Contact & Socials:** Direct mailto triggers and external social links.

---

## 🛠️ Built With

* **Markup:** Semantic HTML5 (`<header>`, `<section>`, `<article>`, `<footer>`)
* **Version Control:** Git & GitHub
